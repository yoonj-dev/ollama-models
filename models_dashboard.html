원클릭으로 각 Modelfile 원문과 하이퍼파라미터를 확인하고 복사할 수 있습니다. 


        

      

    


    
    

      
      
      

        

          

            
              ~/.hermes/config.yaml
            
            

              Hermes Agent Delegation 라우팅 매핑
            

          

          Backend: model_map
        


        

          

            
              

                Route Option
                바인딩된 Ollama 모델
                Provider
                역할 설명
              

            
            
              

                
                  coding default
                
                gemma4-coding:latest
                ollama-launch
                코드 작성, 리팩토링, 버그 수정, 단위 테스트, 아키텍처 분석 전담
              

              

                computer
                gemma4-computer:latest
                ollama-launch
                쉘 명령어 실행, 터미널 작업, 파일 관리, 프로세스 점검, git 제어
              

              

                daily
                gemma4-daily:latest

                텍스트 요약, 번역, 문서 초안 작성, 단순 질의응답 및 데이터 정리

              models: ["gemma4-agent"]

          자주 사용하는 Ollama & Hermes 터미널 명령어
        

        

          터미널에서 바로 복사하여 실행할 수 있는 핵심 명령어 모음입니다.
        


        

          
          

            

              전체 커스텀 모델 일괄 빌드 및 갱신

              Hermes Agent 실행 (기본 gemma4-agent)
              
            

            hermes chat

            ollama run gemma4-coding:latest
